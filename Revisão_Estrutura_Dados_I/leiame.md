Atividade de Estrutura de Dados
Durante as aulas em Estruturas de Dados I, aprendemos sobre Estrutura de Ordenação como Bubble Sort, Selection Sort, Insertion Sort e Quick Sort.
Com essas estruturas conseguimos ordenar dados que estão desordenado de uma forma facil de fazer e prático. No início, começamos com o Bubble é o algoritmo 
mais básico para começar, depois subimos mais o nível com o Selection, o Insertion e o Quick. Aliás, uma curiosidade sobre o Quick é que como os outros algoritmos usam uma memória auxiliar para ajudar na ordenação, o Quick usa um ponteiro de memória.
